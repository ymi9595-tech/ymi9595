# 🌿 베란다 텃밭 · 제철 파종 & 물주기 계산기

단비랩(김영미)의 국내 타깃 무료 도구 웹사이트입니다.
공간·햇빛·이번 달을 고르면 지금 심기 좋은 작물을 추천하고, 심은 날부터 **싹트는 날 · 첫 수확 예정일 · 다음 물주기**까지 계산합니다.

- 라이브: https://ymi9595-tech.github.io/ymi9595/garden-calendar/
- 배포: `main` 브랜치 루트 → GitHub Pages (이 폴더는 `/garden-calendar/` 경로로 서비스)

## 자주 고치는 곳

### 1) 쿠팡파트너스 링크 넣기
`assets/config.js` 의 `supplies` 배열에서 각 항목 `url` 값을 파트너스 단축 링크로 바꾸면 끝입니다.

```js
{ name: '베란다용 배양토(상토) 20L',
  why: '씨앗·모종 심을 때 기본 흙. 가볍고 물 빠짐이 좋아요.',
  url: 'https://link.coupang.com/a/XXXXXXX' }   // ← 여기만 교체
```

지금은 쿠팡 검색 링크가 들어 있어 그대로도 동작합니다.

### 2) 책(상품) 링크·가격 바꾸기
`config.js` 의 `books` 배열. 각 항목은 스마트스토어 단비랩의 실제 상품 주소를 쓰고 있습니다.
상품을 새로 올리면 `url` 을 그 상품 주소(`https://smartstore.naver.com/danbilab/products/{상품번호}`)로 바꿔 주세요.

### 3) 작물·시기 바꾸기
`assets/data.js` 의 `crops` 배열.
- `sow`: 파종·모종 적기인 달 (1~12)
- `germ`: 발아까지 걸리는 일수 `[최소, 최대]`
- `harvest`: 심은 날부터 첫 수확까지 `[최소, 최대]` (과수는 일수 단위, 예: 730 = 2년)
- `water`: `high` / `mid` / `low` — 물주기 간격 계산에 쓰입니다
- `indoorWinter: true` — 겨울(11~2월)에도 실내 창가·베란다에서 심을 수 있는 작물

## 계산 방식

- **물주기 간격** = 작물 물 필요량(2/3/5일) × 계절 계수(여름 1.0 · 봄가을 1.45 · 겨울 1.9) × 공간 계수(실내 1.15 · 베란다 1.0 · 옥상 0.85 · 주말농장 0.9)
- **발아·수확일** = 심은 날 + `data.js` 의 일수 범위
- 기록은 브라우저 `localStorage`(`garden_calendar_v1`)에만 저장됩니다. 서버·회원가입 없음.
