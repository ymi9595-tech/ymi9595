# 영수증 경비장부 (Receipt Expense Tracker)

영수증 사진을 찍고 **상호명·금액**만 넣으면 **부가세와 공급가액이 자동 계산**되어
이번 달 경비 집계와 내역에 바로 쌓이는 사장님용 경비장부입니다.

- 앱 주소: https://ymi9595-tech.github.io/ymi9595/receipt-ai/
- 파일: `index.html` (앱 본체, 단일 파일) · `Code.gs` (구글 시트 백엔드)

## 1. 수업 예시(파란 가계부)와 다른 점

| 수업 예시 가계부 | 이 앱 |
|---|---|
| 파란색 개인 가계부 카드 UI | **다크-그린 + 크림** 사장님 대시보드 |
| 식비·교통비 같은 가계 분류 | **사업 경비 과목** : 재료비 · 소모품비 · 수선유지비 · 식대 · 교통비 · 기타 |
| 금액만 표시 | **총액 / 부가세 / 공급가액**을 함께 관리 (부가세 = 총액 ÷ 11 자동, 공급가액 = 총액 − 부가세) |
| 직접 입력만 | **영수증 촬영 → 1000px 자동 압축 → 미리보기** |
| 단순 합계 | 이번 달 총 경비·건수·부가세 합계·공급가액 합계 + **경비 과목별 지출 바** |
| — | **CSV(엑셀) 내보내기**, **구글 시트 자동 적재**, 영수증 사진 다시 보기 |

## 2. 사용 흐름 (3단계)

1. **영수증 사진** — 카메라 촬영 또는 갤러리 선택(끌어다 놓기도 됨). 1000px JPEG로 자동 압축됩니다.
2. **내용 입력** — 날짜, 경비 과목, 상호명, 총액, 주요 품목. 총액을 넣으면 **부가세·공급가액이 자동 계산**되고 필요하면 고칠 수 있습니다.
3. **장부에 저장하기** — 이번 달 총 경비·건수·부가세·공급가액과 경비 과목별 바, 내역 목록에 바로 반영됩니다.

폰에서는 **홈 화면에 추가**하면 앱처럼 열립니다. (안드로이드 크롬: ⋮ → 홈 화면에 추가)
매장 이름은 ⚙ 설정에서 바꿉니다(기본값 `스터디카페 OG`).

## 3. 구글 시트로도 쓰기

### 방법 A — 시트 안에서 앱 열기 (시트 자동 연동)
1. 새 구글 시트 → **확장 프로그램 → Apps Script**
2. `Code.gs` 전체를 붙여넣기
3. **파일 → HTML**, 이름 `index` 로 만들고 `index.html` 전체를 붙여넣기
4. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자) → URL(`…/exec`) 열기
5. 저장할 때마다 **`영수증경비` 탭**에 한 줄씩 쌓입니다.

### 방법 B — GitHub Pages 앱에서 시트로 보내기
1. 위 1~4로 배포해 `…/exec` URL을 얻는다.
2. 앱 **⚙ 설정 → 구글 시트 연동**에 URL을 넣고 **연결 테스트** → **저장**.

시트 열: `등록일시 · 날짜 · 매장 · 상호명 · 총액 · 공급가액 · 부가세 · 부가세구분 · 경비과목 · 주요품목 · 메모`

## 4. 보관과 안전

- 사진·기록은 **그 브라우저에만** 저장됩니다(IndexedDB/localStorage). 서버로 보내지 않습니다.
- 기기를 바꾸거나 브라우저를 정리하면 기록이 사라지므로 **월말마다 CSV로 백업**하세요.

## 5. 기술 메모

외부 라이브러리 없이 순수 HTML/CSS/JS 한 파일. 이미지 압축은 Canvas
(`createImageBitmap` → 최대 1000px → JPEG 0.82), 사진 원본은 IndexedDB, 목록용 썸네일은
localStorage에 보관합니다. 같은 `index.html`이 GitHub Pages와 Apps Script(HtmlService)
양쪽에서 동작합니다.
