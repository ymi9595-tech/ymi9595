# 사장님 영수증 AI 경비장부 (Receipt AI Expense Tracker)

영수증 사진 한 장이면 **날짜·상호명·총액·부가세·경비분류·주요품목**을 AI가 읽어 정리하는
사업장별 경비장부입니다. 일반 가계부가 아니라 **사업장 5곳을 나눠 쓰는 사장님용 지출 관리**에
맞춰 만들었습니다.

- 배포 주소: https://ymi9595-tech.github.io/ymi9595/receipt-ai/
- 파일: `index.html` (앱 본체, 단일 파일), `Code.gs` (구글 시트 백엔드)

---

## 1. 무엇이 다른가

| 수업에서 본 일반 가계부 | 이 앱 |
|---|---|
| 개인용, 파란색 카드 UI | **따뜻한 다크-그린/크림** 사장님 대시보드 |
| 분류 = 식비·교통비 | **사업장 태그 5곳** (스터디카페 OG · 무인카페 OG · 커피머신 수리 · 체험농장 준비 · 단비랩/기타) |
| 직접 입력 | **영수증 촬영 → 1000px 자동 압축 → Gemini Vision 자동 추출** |
| 단순 합계 | 이번 달 총 경비 · 건수 · **부가세 합계** · 최다 지출 사업장 + **사업장별 지출 바** |
| — | **CSV(엑셀) 내보내기**, **구글 시트 자동 적재**, 영수증 원본 다시 보기 |

경비 분류는 실제 업종에 맞춰 `재료비 · 소모품비 · 수선유지비 · 식대 · 교통비 · 기타` 6가지입니다.

## 2. 바로 쓰기 (GitHub Pages 앱)

1. https://ymi9595-tech.github.io/ymi9595/receipt-ai/ 를 폰 브라우저로 연다.
2. **홈 화면에 추가**하면 앱처럼 열린다. (안드로이드 크롬: ⋮ → 홈 화면에 추가)
3. 사업장 선택 → 카메라 촬영 → **AI로 자동 분석** → 값 확인 → **장부에 저장**.

### Gemini API 키 (1회, 무료)
1. https://aistudio.google.com/apikey → **Create API key**
2. 앱 우측 상단 **⚙ 설정 → Gemini API 키**에 붙여넣고 저장.

> 키는 그 브라우저(localStorage)에만 저장되고 영수증 분석에만 쓰입니다.
> 키가 없어도 **데모** 버튼으로 화면 전체를 시험할 수 있습니다(샘플 영수증 이미지를 그려 넣고 값을 채움).

## 3. 구글 시트로도 쓰기 (두 가지 방법)

### 방법 A — 시트 안에서 앱 열기 (추천, 시트 자동 연동)
1. 새 구글 시트 → **확장 프로그램 → Apps Script**
2. `Code.gs` 전체를 붙여넣기
3. **파일 → HTML**, 이름 `index` 로 만들고 `index.html` 전체를 붙여넣기
4. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자) → URL(`…/exec`) 열기
5. 이 경우 저장할 때마다 **`영수증경비` 탭**에 한 줄씩 자동으로 쌓입니다.

### 방법 B — GitHub Pages 앱에서 시트로 보내기
1. 위 1~4와 같이 배포해 `…/exec` URL을 얻는다.
2. Pages 앱 **⚙ 설정 → 구글 시트 연동**에 URL을 넣고 **연결 테스트** → 저장.
3. 이후 모든 저장이 시트에 함께 기록됩니다.

시트 열: `등록일시 · 날짜 · 사업장 · 상호명 · 총액(원) · 부가세(원) · 부가세구분 · 경비분류 · 주요품목 · 메모`

## 4. 안전과 보관

- 영수증 사진·기록은 **그 브라우저에만** 저장됩니다(IndexedDB/localStorage). 서버로 모이지 않습니다.
- AI 분석 때 사진은 **Google Gemini API로만** 전송됩니다.
- 부가세는 영수증에 인쇄돼 있으면 그 값, 없으면 **총액 ÷ 11** 추정치입니다(구분 열에 `추정` 표시).
- 기기를 바꾸거나 브라우저를 정리하면 기록이 사라지므로 **월말마다 CSV로 백업**하세요.

## 5. 파일 구성

```
receipt_ai_ledger/
├── index.html   # 앱 전체(디자인·로직·AI 호출) — GitHub Pages / Apps Script 공용
├── Code.gs      # 구글 시트 백엔드(doGet/doPost/appendReceipt/ping/setup)
└── README.md    # 이 문서
```

기술 메모: 외부 라이브러리 없이 순수 HTML/CSS/JS 한 파일. 이미지 압축은 Canvas
(`createImageBitmap` → 최대 1000px → JPEG 0.82). AI 호출은 `gemini-2.5-flash`
(실패 시 `gemini-2.0-flash` 자동 재시도), `responseSchema`로 JSON 강제.
