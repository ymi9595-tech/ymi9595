# 영수증 AI 경비장부 (Receipt AI Expense Tracker)

영수증 사진 한 장이면 **날짜 · 상호명 · 총액 · 부가세 · 공급가액 · 경비과목 · 주요품목**을
AI가 읽어 정리하는 사장님용 경비장부입니다.

- 앱 주소: https://ymi9595-tech.github.io/ymi9595/receipt-ai/
- 파일: `index.html` (앱 본체, 단일 파일) · `Code.gs` (구글 시트 백엔드)

## 1. 수업 예시(파란 가계부)와 다른 점

| 수업 예시 가계부 | 이 앱 |
|---|---|
| 파란색 개인 가계부 카드 UI | **다크-그린 + 크림** 사장님 대시보드 |
| 식비·교통비 같은 가계 분류 | **사업 경비 과목** : 재료비 · 소모품비 · 수선유지비 · 식대 · 교통비 · 기타 |
| 금액만 표시 | **총액 / 부가세 / 공급가액** 3가지를 함께 관리 (부가세 없으면 총액 ÷ 11 추정, 공급가액 = 총액 − 부가세) |
| 직접 입력 | **영수증 촬영 → 1000px 자동 압축 → Gemini Vision 자동 추출** |
| 단순 합계 | 이번 달 총 경비·건수·부가세 합계·공급가액 합계 + **경비 과목별 지출 바** |
| — | **CSV(엑셀) 내보내기**, **구글 시트 자동 적재**, 영수증 원본 다시 보기 |

## 2. 바로 쓰기

1. https://ymi9595-tech.github.io/ymi9595/receipt-ai/ 를 폰으로 연다.
2. **홈 화면에 추가**하면 앱처럼 열린다. (안드로이드 크롬: ⋮ → 홈 화면에 추가)
3. 영수증 촬영 → **AI로 자동 분석** → 값 확인 → **장부에 저장**.
4. 매장 이름은 ⚙ 설정에서 바꾼다(기본값 `스터디카페 OG`).

### Gemini API 키 (1회, 무료)
1. https://aistudio.google.com/apikey → **Create API key**
2. 앱 **⚙ 설정 → Gemini API 키**에 붙여넣고 저장.

> 키는 그 브라우저에만 저장되고 영수증 분석에만 쓰입니다.
> 키가 없어도 **데모** 버튼으로 화면 전체를 시험할 수 있습니다(샘플 영수증 이미지를 그려 넣고 값을 채움).

## 3. 구글 시트로도 쓰기

### 방법 A — 시트 안에서 앱 열기 (시트 자동 연동)
1. 새 구글 시트 → **확장 프로그램 → Apps Script**
2. `Code.gs` 전체를 붙여넣기
3. **파일 → HTML**, 이름 `index` 로 만들고 `index.html` 전체를 붙여넣기
4. **배포 → 새 배포 → 웹 앱** (실행: 나 / 액세스: 모든 사용자) → URL(`…/exec`) 열기
5. 저장할 때마다 **`영수증경비` 탭**에 한 줄씩 쌓입니다.

### 방법 B — GitHub Pages 앱에서 시트로 보내기
1. 위 1~4로 배포해 `…/exec` URL을 얻는다.
2. 앱 **⚙ 설정 → 구글 시트 연동**에 URL을 넣고 **연결 테스트** → 저장.

시트 열: `등록일시 · 날짜 · 매장 · 상호명 · 총액 · 공급가액 · 부가세 · 부가세구분 · 경비과목 · 주요품목 · 메모`

## 4. 안전과 보관

- 영수증 사진·기록은 **그 브라우저에만** 저장됩니다(IndexedDB/localStorage). 서버로 모이지 않습니다.
- AI 분석 때 사진은 **Google Gemini API로만** 전송됩니다.
- 기기를 바꾸거나 브라우저를 정리하면 기록이 사라지므로 **월말마다 CSV로 백업**하세요.

## 5. 기술 메모

외부 라이브러리 없이 순수 HTML/CSS/JS 한 파일. 이미지 압축은 Canvas
(`createImageBitmap` → 최대 1000px → JPEG 0.82). AI 호출은 `gemini-2.5-flash`
(실패 시 `gemini-2.0-flash` 자동 재시도), `responseSchema`로 JSON 응답을 강제.
같은 `index.html`이 GitHub Pages와 Apps Script(HtmlService) 양쪽에서 동작합니다.
