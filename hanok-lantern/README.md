# Wish Before It Flies · 한옥 다리 소원 풍등

A one-minute lantern wish game set on a hanok stone bridge at night.

Write a wish quickly and send it up on a lantern. The first letter starts the clock.
If you are too slow — or you pick the lantern the dokkaebi is hiding in — your words
are replaced by a harmless, funny sentence and the sky flies that instead.

- Seven rounds, 10 → 6 seconds, combo scoring
- English by default with an EN / KO toggle
- Result screen with a funny title and a downloadable night-sky card (PNG)
- No sign-in, no tracking, no external JS
- Type: Jua / Gaegu (Korean) + Fredoka One / Quicksand / Patrick Hand (Latin)
  from Google Fonts, applied to the UI and the canvas result card alike

Files
- `index.html` — page, copy lanes (EN/KO), SEO and social metadata
- `assets/style.css` — scene, lanterns, composer, result overlay
- `assets/app.js` — game logic, ambient canvas, sound, result card renderer
- `assets/hanok-night-wide.jpg`, `assets/hanok-night-tall.jpg` — AI-generated backgrounds (no people)
- `assets/og-cover.jpg` — social preview
