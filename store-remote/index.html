📖 처음 한 번만 — 3단계 연결
1
공기계에 MacroDroid 설치

Play 스토어에서 설치 → 매크로 추가 → 트리거 ＋ → 연결성 → Webhook (URL) → 식별자에 cafe1 입력 → 화면에 나오는 주소를 복사합니다.

2
동작에 소리 넣기

동작 ＋ → 미디어 → 사운드 재생/정지 → 아래에서 받은 음성 파일을 고릅니다. 오른쪽 아래 저장을 누르고, 매크로를 길게 눌러 테스트로 소리를 확인하세요.

3
이 앱 ⚙️에 붙여넣기

복사한 주소를 그대로 붙여넣으면 기기 ID만 자동으로 들어갑니다. 나머지 버튼은 식별자만 cafe2 · cafe3 · parking …으로 바꿔 같은 방법으로 만들면 끝입니다.

음성 파일 받기

    · 공기계는 충전기를 꽂아 두고, 설정에서 MacroDroid를 배터리 제한 없음으로 지정해 주세요.
    · 식별자는 영문·숫자만 됩니다. 매크로를 다시 설치했거나 앱 데이터를 지웠다면 기기 ID가 바뀌니 다시 연결해 주세요.
    · 휴대폰 브라우저 메뉴에서 홈 화면에 추가를 누르면 앱처럼 열립니다.

    음성은 ▶로 미리 듣고, ⬇️로 받아 공기계에 넣을 수 있어요.

    매장 연결

    MacroDroid 웹훅 화면의 주소를 통째로 붙여넣어도 됩니다. 기기 ID만 자동으로 남깁니다.

    켜 두면 앱을 열 때 PIN을 한 번 묻습니다. 같은 폰에서 실수로 눌리는 걸 막는 정도의 가벼운 잠금입니다.
