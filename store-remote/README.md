# 매장 방송 리모컨 (store-remote)

휴대폰에서 버튼 한 번으로 매장 안내방송을 내보내는 웹앱입니다.
서버 없이 GitHub Pages에서 바로 열리고, 각 버튼은 MacroDroid의 웹훅 주소로 신호만 보냅니다.
(공기계에 설치한 MacroDroid가 신호를 받아 저장된 음성을 재생합니다.)

## 주소

```
https://ymi9595-tech.github.io/ymi9595/store-remote/
```

## 쓰는 법

1. 공기계(안드로이드)에 MacroDroid를 설치하고, 매크로마다 **Webhook (URL)** 트리거를 추가합니다.
   식별자는 아래 기본값과 같게 넣으면 이 앱의 버튼과 바로 연결됩니다.
2. 트리거 화면에 나오는 주소(`https://trigger.macrodroid.com/<기기 ID>/<식별자>`)를 복사합니다.
3. 이 앱의 **⚙️ 매장 연결**에 그 주소를 붙여넣으면 기기 ID만 남겨 저장됩니다.
4. 주소 뒤에 `?id=<기기 ID>&name=<매장 이름>`을 붙여 열면 입력 없이 자동으로 연결됩니다.

버튼 이름·아이콘·식별자는 **✏️ 편집**이나 **＋ 버튼 추가**로 바꿀 수 있고,
설정은 그 기기의 브라우저(localStorage)에만 저장됩니다. 서버로 보내는 정보는 없습니다.

## 기본 버튼과 음성

| 버튼 | 식별자 | 음성 파일 |
| --- | --- | --- |
| 1인 1음료 안내 | `cafe1` | `audio/01.mp3` |
| 외부음식·음료 안내 | `cafe2` | `audio/02.mp3` |
| 마감·자리정돈 안내 | `cafe3` | `audio/03.mp3` |
| 주차장 금연 안내 | `parking` | `audio/04.mp3` |
| 매너·발 올림 금지 | `manner` | `audio/05.mp3` |
| 무단 주차 금지 | `illegal_parking` | `audio/06.mp3` |
| 쓰레기 무단투기 금지 | `trash` | `audio/07.mp3` |

음성은 웹앱에서 미리 듣고(▶) 파일로 받아(⬇️) 공기계에 넣을 수 있습니다.
식별자는 영문 소문자·숫자·`_`·`-`만 쓸 수 있습니다(MacroDroid 웹훅 규칙).

## 참고

- 웹훅 주소를 아는 사람은 누구나 매크로를 실행할 수 있으니 링크를 공개하지 마세요.
- MacroDroid를 다시 설치하거나 앱 데이터를 지우면 기기 ID가 바뀝니다. 그때는 ⚙️에서 새 주소로 다시 연결하세요.
- 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다(`manifest.webmanifest`).
